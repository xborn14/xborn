# ① RC 低通滤波电路 —— 实验报告

## 1. 电路与参数
- 结构：电阻 R 串在信号路径，电容 C 并在输出与地之间（低通滤波）
- 参数：R = 1 kΩ，C = 1 µF
- 激励：瞬态用方波 0→1 V（脉宽 10 ms、周期 20 ms）；交流分析用 1 V 正弦扫频

电路接线（照着画在纸上，拍照存为 `rc_circuit_手绘.jpg`）：

```
         R = 1 kΩ
Vin ──┬──[====]──┬── Vout
      │          │
    ( ~ )      C = 1 µF
      │          │
     GND ────────┴── GND
```

> 即：信号源一端接 R 左端、另一端接 GND；R 右端为输出节点；C 接在输出节点与 GND 之间；输出从电容两端取。

## 2. 手算过程
- 时间常数：τ = RC = 1×10³ Ω × 1×10⁻⁶ F = **1 ms**
- 截止频率：fc = 1/(2πRC) = 1/(2π×1×10⁻³) ≈ **159.15 Hz**
- 1 kHz 处增益：|H| = 1/√(1+(f/fc)²) = 1/√(1+(1000/159.15)²) ≈ **0.1572**
- 上升时间（10%→90%）：tr ≈ 2.2τ = **2.197 ms**
- fc 处相位：**−45°**
- 充电规律：u_C(t) = V(1 − e^(−t/τ))，t = τ 时达到 63.2%，约 5τ 后基本稳定

## 3. 手算 vs 仿真 对比表

| 物理量 | 手算（理论） | 仿真 | 相对误差 |
|---|---|---|---|
| 时间常数 τ | 1.0000 ms | 1.0000 ms | 0.00 % |
| 截止频率 fc | 159.15 Hz | 159.15 Hz | 0.00 % |
| 上升时间 10%→90% | 2.197 ms | 2.194 ms | 0.14 % |
| fc 处相位 | −45.00° | −45.00° | 0.00 % |
| 1 kHz 处增益 | 0.1572 | 0.1572 | 0.00 % |

仿真测得方波稳态值 V_ss = 0.9997 V（理论 1 V，误差 0.03%）。

## 5. 结论
1. 仿真测得的 τ = 1.0000 ms、fc = 159.15 Hz 与手算完全一致（误差 0.00%），验证了 RC 低通滤波的频率特性。
2. 方波输入下输出按指数规律充放电：经 1 τ 达到稳态值的 63.2%，约 5 τ 后基本稳定，与一阶电路理论一致。
3. 幅频曲线在 fc 处下降 3 dB，之后以 −20 dB/十倍频滚降；相频曲线在 fc 处为 −45°。
