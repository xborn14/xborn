## 常用命令

### 目录操作

| 命令 | 用途 |
|------|------|
| `cd 路径` | 进入目录，`cd ..` 返回上一级，`cd ~` 回主目录 |
| `ls`（Windows 用 `dir`） | 列出当前目录文件 |
| `mkdir 名称` | 新建文件夹 |
| `pwd` | 显示当前所在路径 |

### Git 常用命令

| 命令 | 用途 |
|------|------|
| `git init` | 当前目录初始化为仓库 |
| `git clone 地址` | 克隆远程仓库到本地 |
| `git status` | 查看当前改动状态 |
| `git add 文件名` | 暂存改动（`.` 表示全部） |
| `git commit -m "说明"` | 提交到本地仓库 |
| `git push` | 推送到远程仓库 |
| `git pull` | 拉取远程最新代码 |
| `git log --oneline -5` | 查看最近 5 条提交记录 |
| `git branch` | 查看分支 |
| `git checkout 分支名` | 切换分支 |
| `git merge 分支名` | 合并分支到当前 |
| `git remote -v` | 查看远程仓库地址 |
| `git remote set-url origin 新地址` | 修改远程地址 |
| `git diff` | 查看未暂存的改动 |
